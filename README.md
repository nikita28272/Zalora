# Бот сигналов на футбол

Telegram-бот, который ищет ценные ставки (value bets) на футбол: топ-5 лиг Европы и Лигу чемпионов.
Решение принимаете вы: бот только присылает разбор и сигнал.

> ⚠️ Букмекер всегда имеет преимущество за счёт маржи. Бот не гарантирует выигрыш. Первые 1–2 месяца
> он ведёт «бумажный» журнал: сначала проверьте статистику, потом решайте, ставить ли реальные деньги.
> Ставьте только у легальных букмекеров и только те деньги, которые готовы потерять.

## Иерархия

```
👤 Владелец (вы): окончательное решение, отметка «поставил / не ставил»
└── 🧠 Главный аналитик (босс): ставит задачи, выслушивает всех, выносит вердикт
    ├── 💹 Рынок: вероятности из линий букмекеров без маржи
    ├── 📊 Статистик: модель Пуассона по сезону, после матча проверяет исход
    ├── 📰 Агент новостей: травмы, составы, мотивация (RSS + веб-поиск)
    ├── 🌍 Зарубежные аналитики: самые частые прогнозы (веб-поиск)
    ├── 😈 Адвокат дьявола: сильнейшие аргументы против каждого исхода
    └── 💰 Финансист: банк, размер ставки, лимиты, учёт результатов
```

**Правило босса:** каждый подчинённый докладывает по **каждому** исходу (П1, X, П2, ТБ 2.5, ТМ 2.5).
Неполный отчёт возвращается на доработку. Если кто-то не доложил даже после повторного задания,
главный не выносит вердикт.

## Цикл одной ставки

1. Рынок и статистик находят матчи, где возможен перевес (только прематч: матчи, до начала
   которых меньше `MIN_MINUTES_BEFORE_KICKOFF` минут, не разбираются).
2. Главный поручает работу новостям и зарубежным аналитикам, затем адвокату дьявола.
3. Финансист докладывает банк и лимиты.
4. Главный оценивает каждый исход и присылает вам в Telegram сигнал: таблицу по всем исходам,
   позицию каждого подчинённого, минимальный коэффициент и сумму от финансиста.
5. Вы жмёте **«✅ Поставил»** и пишете коэффициент (и сумму, если она другая) или **«❌ Не ставил»**.
   Без отметки до начала матча ставка считается несделанной: лайв не учитываем.
6. После матча статистик проверяет исход, финансист меняет банк (только по реальным ставкам),
   главный докладывает вам итог и новый баланс.

Защита от самоуверенности: вероятность главного не может уйти от рынка дальше, чем на
`MAX_PROB_DEVIATION` (8 п.п.). Финансист ставит 1/4 Келли, не больше 2% банка на ставку,
не больше 3 сигналов в день, останавливается при дневном убытке 5% и после 4 проигрышей подряд.

### Про российских букмекеров

Линий Fonbet, Winline и других БК с лицензией ЦУПИС нет в открытых API. Поэтому бот
считает вероятности по международному рынку и в сигнале пишет **минимальный коэффициент**:
«брать П1 при кэфе не ниже 2.15». Вы открываете свою БК: если там столько же или больше, ставка
имеет перевес. Если меньше, сигнал пропускаете.

## Что нужно получить (всё бесплатно, кроме Claude API)

| Что | Где | Цена |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Telegram → @BotFather → `/newbot` | бесплатно |
| `ANTHROPIC_API_KEY` | https://console.anthropic.com → API Keys | по факту использования |
| `ODDS_API_KEY` | https://the-odds-api.com → тариф Free | 500 кредитов/мес бесплатно |
| `FOOTBALL_DATA_API_KEY` | https://www.football-data.org/client/register | бесплатно |
| `TELEGRAM_OWNER_ID` | бот пришлёт сам при первом сообщении | — |

Ключи вводятся только в файл `.env` на сервере. Никому их не пересылайте.

## Запуск на сервере (VPS, Ubuntu)

```bash
# 1. Установить Docker (один раз)
curl -fsSL https://get.docker.com | sh

# 2. Скачать проект
git clone https://github.com/nikita28272/Zalora.git
cd Zalora

# 3. Создать файл с ключами
cp .env.example .env
nano .env            # вставить ключи, сохранить: Ctrl+O, Enter, Ctrl+X

# 4. Запустить
docker compose up -d --build

# Логи
docker compose logs -f
```

Узнать свой Telegram ID: оставьте `TELEGRAM_OWNER_ID` пустым, запустите бота и напишите ему.
Он пришлёт ID. Впишите его в `.env` и перезапустите: `docker compose restart`.

Бот отвечает только владельцу. Остальным он ничего не отвечает.

Обновление после изменений в коде:

```bash
git pull && docker compose up -d --build
```

### Запуск без Docker (для теста на компьютере)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить
python -m bot.main
```

## Команды бота

| Команда | Что делает |
|---|---|
| `/matches` | ближайшие матчи (48 ч): вероятности рынка и модели, 🔎 = возможный перевес |
| `/analyze N` | полный разбор матча N всеми агентами |
| `/scan` | найти сигналы прямо сейчас |
| `/signals` | открытые сигналы и ваши отметки |
| `/stats` | ROI за месяц и за всё время: ваши ставки и все сигналы системы |
| `/history` | последние рассчитанные сигналы |
| `/bank 15000` | задать банк (показать без числа) |
| `/limits` | лимиты финансиста |
| `/resume` | снять паузу после серии проигрышей |
| `/usage` | расход на Claude API за 30 дней |
| `/settle` | проверить исходы завершённых матчей вручную |

По расписанию: автоскан каждый день в `SCAN_TIME`, расчёт итогов в `SETTLE_TIME`.

## Сколько это стоит

* **Сервер:** VPS за $4–10 в месяц.
* **Линии и статистика:** бесплатные тарифы. Один скан в день расходует около 12 из 500 кредитов The Odds API.
* **Claude API.** Платятся только разборы матчей, где модель увидела перевес. Один полный разбор
  (4 агента и до 6 веб-поисков) на `claude-opus-5-5` обходится примерно в $0.3–0.5. Это оценка:
  точная сумма видна в `/usage` и в конце каждого разбора.
  * По умолчанию не больше 2 разборов за скан и 3 в день.
  * Чтобы уложиться в ~$20 в месяц, переведите помощников на `LLM_MODEL_AGENTS=claude-sonnet-5-5`
    (примерно вдвое дешевле) или уменьшите `MAX_LLM_ANALYSES_PER_DAY`.

## Как понять, работает ли система

`/stats` показывает три блока:

* **ваши ставки за месяц** и **за всё время**: реальный ROI по вашим коэффициентам и суммам;
* **все сигналы системы на бумаге** по минимальному коэффициенту: точность главного аналитика,
  даже если вы ставили не всё.

Реалистичные ориентиры для линии топ-лиг:

* устойчивый ROI **+3…8%** на дистанции 100+ ставок — уже сильный результат;
* 30% ROI в месяц может случиться на коротком отрезке за счёт везения, но не держится долго;
* если после 100 сигналов ROI системы отрицательный, на реальные деньги не играть: нужно менять
  модель или поднимать `MIN_EDGE`. Поднимать ставки, чтобы «отыграться» или выйти на план, нельзя.

## Структура проекта

```
bot/
  config.py          настройки и список лиг
  main.py            запуск, расписание
  pipeline.py        главный конвейер (отбор, агенты, сигналы, расчёт)
  db.py              журнал сигналов (SQLite)
  data/              источники: линии, статистика, новости, сопоставление названий
  analysis/          рынок без маржи, модель Пуассона, финансист
  agents/            агенты на Claude API и форматы их отчётов
  tg/                команды и тексты Telegram
tests/               тесты (python -m pytest)
```

## Если ставки перестали быть игрой

Если ставки начинают влиять на деньги, сон или настроение, остановитесь. Бесплатная помощь:
горячая линия «Анонимные игроки» и сообщество GamAnon.
