# Бот сигналов на футбол и хоккей

Telegram-бот, который ищет ценные ставки (value bets): ⚽ топ-5 лиг Европы и Лига чемпионов, 🏒 НХЛ, 🏀 НБА.

| Вид спорта | Рынки | Статистика |
|---|---|---|
| ⚽ Футбол | П1 / X / П2, тотал 2.5 | football-data.org |
| 🏒 НХЛ | П1 / П2 с ОТ и буллитами, 1X2 основного времени, тотал (линия букмекера), фора ±1.5 | открытый API НХЛ, ключ не нужен |
| 🏀 НБА | П1 / П2, фора и тотал очков (всё с овертаймом) | открытые данные ESPN, ключ не нужен |

В хоккее тотал и фора считаются по итоговому счёту с овертаймом (победа в буллитах = +1 гол),
1X2 — по основному времени. Если 1X2 основного времени нет в бесплатной линии, бот оценивает его
по линии П1/П2 с ОТ и помечает коэффициент как оценочный.
Решение принимаете вы: бот только присылает разбор и сигнал.

> ⚠️ Букмекер всегда имеет преимущество за счёт маржи. Бот не гарантирует выигрыш. Первые 1–2 месяца
> он ведёт «бумажный» журнал: сначала проверьте статистику, потом решайте, ставить ли реальные деньги.
> Ставьте только у легальных букмекеров и только те деньги, которые готовы потерять.

## Иерархия

```
👤 Владелец (вы): окончательное решение, отметка «поставил / не ставил»
└── 🧠 Главный аналитик (босс): ставит задачи, выслушивает всех, выносит вердикт
    ├── 💹 Рынок: вероятности из линий букмекеров без маржи
    ├── 📊 Статистик: модель Пуассона по сезону, после матча проверяет исход
    ├── 📰 Агент новостей: травмы, составы, мотивация (RSS + веб-поиск)
    ├── 🌍 Зарубежные аналитики: самые частые прогнозы (веб-поиск)
    ├── 😈 Адвокат дьявола: сильнейшие аргументы против каждого исхода
    └── 💰 Финансист: банк, размер ставки, лимиты, учёт результатов
```

**Правило босса:** каждый подчинённый докладывает по **каждому** исходу (П1, X, П2, ТБ 2.5, ТМ 2.5).
Неполный отчёт возвращается на доработку. Если кто-то не доложил даже после повторного задания,
главный не выносит вердикт.

## Два режима работы агентов

| | **Босс в чате** (`AGENTS_MODE=manual`, по умолчанию) | **Через API** (`AGENTS_MODE=api`) |
|---|---|---|
| Где работают 📰 🌍 😈 и 🧠 | в чате Claude Code, по вашей команде | прямо в боте, автоматически |
| Нужен ключ Claude API | нет | да, с console.anthropic.com |
| Ваши действия | скопировать досье в чат и вердикт обратно | только кнопки «Поставил / Не ставил» |
| Стоимость нейросети | в рамках вашей подписки Claude | ~$0.2–0.4 за разбор |

### Режим «босс в чате» по шагам

1. **SCAN_TIME** — бот присылает все матчи футбола и хоккея на 48 часов и кнопку **«🔍 Анализ»**.
   Наверху — **«⭐ Стоит разобрать»**: до 5 матчей, где перевес вероятнее всего (модель + рынок,
   реальные кэфы, без уже разобранных). Кнопка ⭐ сразу открывает досье.
2. **«🔍 Анализ» → номер матча** — приходит досье в блоке с кнопкой «Копировать».
3. Копируете досье в чат Claude Code с этим репозиторием. Босс работает по [BOSS.md](BOSS.md):
   субагенты — новости, зарубежные аналитики, РУ-аналитики (российские прогнозы, публика, кэфы
   российских контор), продвинутая статистика (xG, вратари, везение),
   затем адвокат дьявола; босс разбирает все исходы и выбирает **два лучших** (с перевесом — первыми, иначе лучшие из остальных).
4. Последняя строка ответа — `/verdict 7 home 0.54 under 0.56 medium`. Отправляете её боту.
5. Бот показывает оба исхода с советом финансиста; под каждым — **«✅ Сделал»** (потом кэф и сумма,
   `2.15 500`) или **«❌ Не ставил»**. Пока нет вашей ставки («✅ Сделал»), новый `/verdict` заменяет прежний.
   Перед матчем бот сам напомнит о **поздней проверке** (хоккей — за 2 часа: вратари; футбол — за
   50 минут: составы; в том числе ночью) и пришлёт блок «ПРОВЕРКА #N» для Claude.
   То же — кнопкой «🥅 Поздняя проверка» или `/check 7`.
6. **SETTLE_TIME** на следующий день — итог по этим исходам: ваши ставки меняют банк,
   остальные идут в статистику на бумаге 📊 (отдельно «с перевесом» и «без перевеса»).

## Цикл одной ставки

1. Рынок и статистик находят матчи, где возможен перевес (только прематч: матчи, до начала
   которых меньше `MIN_MINUTES_BEFORE_KICKOFF` минут, не разбираются).
2. Главный поручает работу новостям и зарубежным аналитикам, затем адвокату дьявола.
3. Финансист докладывает банк и лимиты.
4. Главный оценивает каждый исход и присылает вам в Telegram сигнал: таблицу по всем исходам,
   позицию каждого подчинённого, минимальный коэффициент и сумму от финансиста.
5. Вы жмёте **«✅ Поставил»** и пишете коэффициент (и сумму, если она другая) или **«❌ Не ставил»**.
   Без отметки до начала матча ставка считается несделанной: лайв не учитываем.
6. После матча статистик проверяет исход, финансист меняет банк (только по реальным ставкам),
   главный докладывает вам итог и новый баланс.

Защита от самоуверенности: вероятность главного не может уйти от рынка дальше, чем на
`MAX_PROB_DEVIATION` (8 п.п.). Финансист ставит 1/4 Келли, не больше 2% банка на ставку,
не больше 3 сигналов в день, останавливается при дневном убытке 5% и после 4 проигрышей подряд.

### Про российских букмекеров

Линий Fonbet, Winline и других БК с лицензией ЦУПИС нет в открытых API. Поэтому бот
считает вероятности по международному рынку и в сигнале пишет **минимальный коэффициент**:
«брать П1 при кэфе не ниже 2.15». Вы открываете свою БК: если там столько же или больше, ставка
имеет перевес. Если меньше, сигнал пропускаете.

## Что нужно получить (всё бесплатно)

| Что | Где | Цена |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Telegram → @BotFather → `/newbot` | бесплатно |
| `ODDS_API_KEY` | https://the-odds-api.com → тариф Free | 500 кредитов/мес бесплатно |
| `FOOTBALL_DATA_API_KEY` | https://www.football-data.org/client/register | бесплатно |
| — | статистика НХЛ: открытый API лиги, ключ не нужен | бесплатно |
| — | статистика НБА: открытые данные ESPN, ключ не нужен | бесплатно |
| `TELEGRAM_OWNER_ID` | бот пришлёт сам при первом сообщении | — |
| `ANTHROPIC_API_KEY` | только для режима `api`: https://console.anthropic.com → API Keys | по факту использования |

Ключи вводятся только в файл `.env` на сервере. Никому их не пересылайте.

## Установка с телефона

Понадобится приложение **Termius** (App Store / Google Play) и сервер (VPS) с Ubuntu.

1. Получите ключи (таблица выше) и сохраните их в заметках.
2. Арендуйте VPS: Ubuntu 22.04 или 24.04, 1 CPU и 1–2 ГБ памяти достаточно. Хостинг пришлёт IP-адрес и пароль root.
3. В Termius: **New Host** → Address: IP сервера, Username: `root`, Password: пароль → Connect.
4. Вставьте в терминал одну строку и нажмите Enter:

   ```bash
   git clone -b ccr-cf5a84bc-bw3cth https://github.com/nikita28272/Zalora.git && cd Zalora && bash scripts/setup.sh
   ```

   Скрипт по очереди спросит 3 ключа и банк, сам поставит Docker и запустит бота.
   Если на сервере нет git: сначала `apt update && apt install -y git`.
5. Напишите своему боту в Telegram что угодно. Он ответит вашим ID. В Termius выполните:

   ```bash
   bash scripts/set.sh TELEGRAM_OWNER_ID ВАШ_ID
   ```

6. Напишите боту `/start`. Готово, телефон и Termius больше не нужны.

Полезные команды (из папки `Zalora`, войти в неё: `cd Zalora`):

| Что | Команда |
|---|---|
| Проверить ключи и источники | `bash scripts/check.sh` |
| Как модель оценила команды | `bash scripts/diag.sh NHL "Vegas" "Nashville"` |
| Поменять настройку | `bash scripts/set.sh MAX_LLM_ANALYSES_PER_DAY 2` |
| Посмотреть логи | `docker compose logs --tail 50` |
| Обновить бота | `git pull && docker compose up -d --build` |
| Остановить | `docker compose down` |

## Запуск на сервере вручную (VPS, Ubuntu)

```bash
curl -fsSL https://get.docker.com | sh

cd Zalora

```

## Команды бота

Всё основное — кнопками. Внизу экрана постоянное меню:

```
[ 📅 Матчи      ]   [ 🔍 Анализ     ]
[ 📌 Прогнозы и ставки ] [ 📊 Статистика ]
[ 💰 Банк      ]   [ 💳 Кредиты    ]
[ ⚙️ Ещё — история, лимиты, проверка итогов, снять паузу, помощь ]
```

Под списком матчей — кнопки с номерами (досье одним нажатием), в «Моих сигналах» — «✅ / ❌»
у неотмеченных сигналов, в «Банке» — «✏️ Изменить». Командой остаётся только `/verdict …`
из ответа босса. Те же действия доступны и командами:

| Команда | Что делает |
|---|---|
| `/matches` | ближайшие матчи (48 ч): вероятности рынка и модели, 🔎 = возможный перевес |
| `/analyze N` | досье матча N для босса (в режиме `api` — полный разбор агентами) |
| `/scan` | кандидаты дня с досье (в режиме `api` — поиск сигналов агентами) |
| `/verdict 7 home 0.54 under 0.56 medium` | топ-2 босса из чата: бот покажет оба исхода с кнопками |
| `/signals` | открытые сигналы и ваши отметки |
| `/stats` | ROI за месяц и за всё время: ваши ставки и все сигналы системы |
| `/history` | последние рассчитанные сигналы |
| `/bank 15000` | задать банк (показать без числа) |
| `/limits` | лимиты финансиста |
| `/resume` | снять паузу после серии проигрышей |
| `/credits` | остаток кредитов The Odds API (проверка кредиты не тратит) |
| `/usage` | расход на Claude API за 30 дней (режим `api`) |
| `/settle` | проверить исходы завершённых матчей вручную |

По расписанию: автоскан каждый день в `SCAN_TIME`, расчёт итогов в `SETTLE_TIME`.

## Сколько это стоит

* **Сервер:** VPS за $4–10 в месяц.
* **Линии и статистика:** бесплатные тарифы. Запрос линий по лиге стоит столько кредитов The Odds API,
  сколько в нём рынков (футбол 2, НХЛ 3–4, НБА 3), а в месяц бесплатно 500. Как бот экономит:
  * **Бесплатная разведка:** сначала узнаёт (без трат), в каких лигах есть матчи в ближайшие 48 часов,
    и покупает линии только по ним.
  * **Память о рынках:** если API не принимает какой-то рынок, бот запоминает и не пробует снова.
  * **Кеш:** `/matches` и досье берут линии не старше 2 часов, ежедневный скан — не старше часа.
  * **Автопилот бюджета:** остаток кредитов делится на дни до обновления лимита (`ODDS_RESET_DAY`).
    Если на сегодня не хватает, откладываются лиги с низким приоритетом (порядок в `ENABLED_LEAGUES`).
  * **Отчёт:** под `/matches` и кандидатами — сколько потрачено и что пропущено; остаток — `/credits`.
* **Режим «босс в чате» (по умолчанию):** нейросеть работает в рамках вашей подписки Claude,
  отдельной оплаты нет. Разборы с субагентами расходуют лимиты подписки.
* **Режим `api`.** Платятся только 4 агента на нейросети (новости, эксперты, адвокат дьявола, босс)
  и только когда идёт разбор матча. Рынок, статистик, финансист и сам бот работают бесплатно.
  Подписка Claude Pro/Max работу бота не покрывает: API оплачивается отдельно на console.anthropic.com.

  По умолчанию включён **экономичный режим**: босс на `claude-opus-5-5`, помощники на `claude-sonnet-5-5`.

  | Режим | Один разбор | 3 разбора в день, каждый день |
  |---|---|---|
  | Экономичный (по умолчанию) | ~$0.2–0.27 | ~$18–24 в месяц |
  | Полный (`LLM_MODEL_AGENTS=claude-opus-5-5`) | ~$0.3–0.5 | ~$27–45 в месяц |

  Это оценки. Реальная стоимость каждого разбора видна в конце сообщения и в `/usage`.
  На деле обычно выходит меньше: платный разбор запускается только там, где модель увидела перевес.
  Лимиты: не больше 2 разборов за скан и 3 в день (`MAX_LLM_MATCHES_PER_SCAN`, `MAX_LLM_ANALYSES_PER_DAY`).

## Как понять, работает ли система

`/stats` показывает три блока:

* **ваши ставки за месяц** и **за всё время**: реальный ROI по вашим коэффициентам и суммам;
* **все сигналы системы на бумаге** по минимальному коэффициенту: точность главного аналитика,
  даже если вы ставили не всё.

Реалистичные ориентиры для линии топ-лиг:

* устойчивый ROI **+3…8%** на дистанции 100+ ставок — уже сильный результат;
* 30% ROI в месяц может случиться на коротком отрезке за счёт везения, но не держится долго;
* если после 100 сигналов ROI системы отрицательный, на реальные деньги не играть: нужно менять
  модель или поднимать `MIN_EDGE`. Поднимать ставки, чтобы «отыграться» или выйти на план, нельзя.

## Структура проекта

`BOSS.md` — инструкция для босса в режиме «босс в чате», `CLAUDE.md` указывает на неё.

```
bot/
  config.py          настройки и список лиг
  main.py            запуск, расписание
  pipeline.py        главный конвейер (отбор, агенты, сигналы, расчёт)
  db.py              журнал сигналов (SQLite)
  data/              источники: линии, статистика, новости, сопоставление названий
  analysis/          рынок без маржи, модель Пуассона, финансист
  agents/            агенты на Claude API (режим api) и форматы их отчётов
  check.py           проверка ключей и источников (scripts/check.sh)
  tg/                команды и тексты Telegram
tests/               тесты (python -m pytest)
```

## Если ставки перестали быть игрой

Если ставки начинают влиять на деньги, сон или настроение, остановитесь. Бесплатная помощь:
горячая линия «Анонимные игроки» и сообщество GamAnon.
