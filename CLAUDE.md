# Zalora: бот сигналов на футбол и хоккей

Telegram-бот для ставок на футбол (топ-5 лиг и Лига чемпионов) хоккей (НХЛ) и баскетбол (НБА), только прематч, с иерархией
«владелец → главный аналитик (босс) → подчинённые». Код в `bot/`, описание в `README.md`.

## Если владелец прислал досье

Текст, начинающийся с `ДОСЬЕ #N ДЛЯ БОССА`, — это задание для тебя как главного аналитика
в режиме «босс в чате». Действуй строго по [BOSS.md](BOSS.md): субагенты (новости,
зарубежные и РУ-аналитики, продвинутая статистика, адвокат дьявола) → проверка докладов по каждому исходу → вердикт →
ответ владельцу с командой `/verdict` в конце (только если ставка есть).

Текст, начинающийся с `ПРОВЕРКА #N ДЛЯ БОССА`, — поздняя проверка перед матчем: раздел
«Поздняя проверка» в BOSS.md (один субагент, затем «оставляем» или новый `/verdict`).

Разбор досье и проверки — не задача по коду: файлы не меняй и ничего не коммить.

## Разработка

- Тесты: `python -m pytest -q tests`
- Общение с владельцем — на русском, просто и без жаргона: владелец работает с телефона.
